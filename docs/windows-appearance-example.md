# Пример оформления контролов Golphi

Пример [windows-appearance](../examples/windows-appearance/main.go) использует фиксированные размеры в логических единицах. В Windows приложение включает Common Controls v6 через собственный [манифест](../examples/windows-appearance/app.manifest.xml). Готовый ресурс уже включён в пакет примера. Порядок его регенерации описан в [инструкции по ресурсам](windows-resources.md).

## Сборка

В корне проекта на Windows (PowerShell):

```powershell
$env:CGO_ENABLED = '0'
$env:GOOS = 'windows'
$env:GOARCH = 'amd64'
go build -ldflags="-H windowsgui" -o windows-appearance.exe ./examples/windows-appearance
.\windows-appearance.exe
```

На Linux с GTK4/X11:

```sh
CGO_ENABLED=0 go run ./examples/windows-appearance
```

## Что проверить на Windows

Запустите отдельный процесс при масштабе 100% (96 DPI), затем закройте окно, установите 150% и запустите новый процесс (144 DPI). Используйте фактический DPI запуска из журнала нативных проверок WIN-01.

1. Прочитайте верхнюю подпись, первое поле и кнопку «Добавить подпись». Текст помещается целиком. У «Й» и «ё» видны верхние элементы, у «Д», «д», «Ц», «ц», «Щ» и «щ» видны нижние.
2. Во втором поле нажмите `End`, затем `Home`. В конце видно «Конец строки.», в начале снова видна кириллица. Введите несколько букв и выделите их через `Shift` со стрелками. Поле прокручивается по горизонтали и сохраняет границы.
3. Проверьте тесные кнопку, поле и подпись в нижней части окна. Длинный текст остаётся в пределах каждого контрола. В каждой из двух нижних подписей видно начало «Край». Остальная часть строки обрезается у правой границы соответствующей панели.
4. Нажмите «Добавить подпись», «Скрыть подпись», затем «Вернуть подпись». Справа от кнопки появляется, скрывается и снова появляется подпись. Её шрифт при каждом появлении совпадает со шрифтом верхней строки. Остальные контролы сохраняют положение.
5. Сохраните снимки на обоих масштабах. Для проверки фокуса и выделения при переносе существующего поля используйте [пример динамического дерева](dynamic-tree-example.md).

Снимки и ручные наблюдения дополняют нативные проверки DPI, visual styles и шрифта.
