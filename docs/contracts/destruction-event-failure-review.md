## Точный текст миграции Scope — сохранённый аудит

При sync дельты применены, а второй абзац Scope and terminology основной component-events заменён следующим подготовленным текстом. Первый абзац Parent сохранён дословно. Блок сохранён как аудит точного исходного Markdown относительно openspec/specs/component-events/spec.md:

```markdown
Правила отложенной повторной доставки определены требованиями «Deferred and coalesced repeated changes», «Destruction cancels unstarted component notifications», «Detachment cancels pending text notifications», «Pending text notification follows the current handler», «Disabling cancels queued and accumulated text notifications» и «Comparison restarts after disabling» ниже; паника обработчика и аварийная остановка определены [спецификацией application-failure](../application-failure/spec.md). Обычная остановка, Post, взаимные изменения компонентов, новое накопление после отсоединения/присоединения внутри одного callback и прочие неописанные сочетания остаются открытыми.
```

Автоматическое слияние Requirements само по себе Scope не обновляет; миграция Scope выполнена отдельно. Относительная ссылка на application-failure проверена, ссылки на перемещённое изменение в актуальных документах обновлены. Исторический архив предыдущего изменения сохранён.
