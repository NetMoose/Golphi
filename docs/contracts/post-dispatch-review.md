Весь E0 и Q-04/Q-05/Q-06 не закрыты. Полный [реестр изменения](../../openspec/changes/define-post-dispatch-contract/design.md#open-questions) сохраняется: обычная остановка и повторный Run; ошибки/паники очистки и диагностика; порядок относительно native events/OnChange, взаимные изменения и справедливость; ожидание результата и индивидуальная отмена, специальный API с владельцем; получатель Post, ошибки и ёмкость/перегрузка; bootstrap и точная готовность UI-потока; ошибки живых компонентов и сигнатуры событий; оставшиеся вопросы иерархий/native lifecycle и Q-01–Q-14. ### New openspec/specs/post-dispatch/spec.md: Purpose and Scope

```markdown
## Purpose

Определить наблюдаемый контракт принятия и выполнения задач Post на UI-потоке Golphi и их отмены при аварийной остановке приложения.

## Scope

Контракт относится к обычному Post(fn), без владельца. Обычная остановка, ожидание результата, индивидуальная отмена, задачи с владельцем, порядок относительно native events/OnChange, bootstrap UI-потока и ошибки очистки остаются открытыми. Точный получатель метода и публичные типы ошибок не выбираются.
```

### openspec/specs/application-failure/spec.md: Purpose and Scope

```markdown
## Purpose

Определить аварийную остановку прикладных событий и задач Post Golphi при панике прикладного обработчика или функции Post и возврат диагностики вызывающему Form.Run() коду.

## Scope

Контракт касается паники прикладного обработчика или функции Post, прекращения прикладной доставки, отмены ожидающих уведомлений и всех ещё не начатых задач Post и отклонения новых Post при аварийной остановке. Ошибки и паники самой очистки, сбои внутренних механизмов и обычная остановка приложения остаются открытыми. Возврат диагностики через Form.Run() предполагает успешную очистку без дополнительного сбоя.
```

## Организация работы

Ветка feature/post-dispatch-contract создана от актуального develop (4d1def3) без worktree. Через Subagent Driven Development независимые контракты подготовлены параллельно; согласование дизайна началось после review контрактов.
