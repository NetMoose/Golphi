# Golphi

Экспериментальный нативный GUI-фреймворк для Go с компонентной моделью, близкой к Delphi VCL. В репозитории реализован узкий MVP: одна форма, Edit, Button и Label, Win32 и GTK4, события и передача фоновой работы через `ui.Post`. Это ещё не завершение E0 или полного E1 и не стабильный публичный API.

[Одинаковый пример для обеих платформ](examples/hello/main.go) создаёт логическое дерево через `ui.NewForm()` и `ui.NewEdit/NewButton/NewLabel(form)`, явно задаёт Parent, размеры и обработчики `func()`, затем вызывает `form.Run()`. Запуск выполняется на startup thread; импорт `ui` закрепляет его. Допускается одна попытка Run на процесс; Post принимает задачи только после готовности и закрывается при остановке.

Сборка примера без C toolchain:

```sh
CGO_ENABLED=0 go build -o hello ./examples/hello
```

Linux использует установленный системный GTK4 runtime; заголовки GTK и pkg-config для сборки приложения не требуются. Windows использует системные DLL. Версии и воспроизводимые команды — в [инструкции сборки](docs/mvp-build.md).

Фактическая Windows-цель — Windows 11 Pro/amd64 build 26100, 100% (96 DPI); native-проба, обе автоматические native suites и все ручные сценарии примера пройдены. Все ручные сценарии Linux также подтверждены пользователем; узкий MVP принят. Windows 10 не проверена. Свидетельства и ограничения приведены в [отчёте MVP](docs/mvp-validation.md).

`SetClientSize` задаёт точный клиентский размер; `SetBounds` задаёт фиксированные координаты и минимальные размеры контролов, которые тема может увеличить для сохранения нативного вида. Геометрия задаётся до Run; layout, resizing и автоматическое устранение пересечений не входят в MVP. Также отложены Panel, динамическое создание и перенос во время работы, несколько окон, Qt, Auto, формы и дизайнер.
