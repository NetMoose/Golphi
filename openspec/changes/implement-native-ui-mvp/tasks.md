# Tasks

Реализация начинается только отдельным openspec-apply-change. Каждый этап использует Subagent Driven Development; непересекающиеся задачи параллельны при возможности, общие интерфейсы согласуются раньше зависимых работ. Ветка от develop без worktree, Git только у координатора. Все незакрытые вопросы design.md сохраняются. Тесты/документация создаются вместе с соответствующим кодом, отметка выполнения требует свидетельств.
