# Tasks

Реализация начинается отдельным openspec-apply-change. Ветка от актуальной develop без worktree; Subagent Driven Development, независимые задачи параллельны при возможности, Git только у координатора. Каждый этап завершается review и commit/push с проверкой remote HEAD. Открытые вопросы design.md не закрываются молча. Нативные результаты Windows требуют фактического запуска.

Сокращение объёма от 2 ноября 2026 года: курсор и выделение при пересоздании Edit перенесены на следующий этап; текст сохраняется. Проверки позиций сохраняемого native Edit, фокуса, событий и отката остаются обязательными. Прежние отметки [x] отражают уже выполненную работу; согласование реализации с новой границей выполнено в 4.5. Нативная проверка новой Windows-сборки подтверждена в 4.2–4.3; итоговое review этапа 4.4 остаётся открытым.
