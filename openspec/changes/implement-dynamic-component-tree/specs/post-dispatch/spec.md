# Spec Delta

## ADDED Requirements

### Requirement: Unrecoverable tree failure closes dispatch
При аварийном отказе восстановления дерева Golphi SHALL закрывать приём Post, отменять все ещё не начатые задачи и не запускать новые. Очистка MUST NOT возобновлять доставку. Прежняя однозначная граница гонки принятия и остановки SHALL сохраняться; уже принятый nil не гарантирует выполнение.

#### Scenario: Queued work at failed rollback
- **WHEN** при ожидающих Post восстановить прежнее нативное дерево невозможно
- **THEN** ожидающие задачи отменены, новые Post отклоняются, текущая функция может завершиться

#### Scenario: Worker races fatal tree failure
- **WHEN** worker отправляет Post одновременно с аварийной остановкой из-за неудачного восстановления
- **THEN** задача либо принята до границы и может быть отменена, либо отклонена без очереди после границы
