# Tasks

Начало реализации — отдельный запрос `openspec-apply-change`. Ветка от актуальной `develop`, без worktree. Применять Subagent Driven Development; после baseline независимые задачи ресурсов и backend выполнять параллельно при возможности с явным владением файлами, Git только у координатора. Каждый этап завершается review и commit/push с проверкой remote HEAD. Статус отмечается по фактическому завершению проверок; наличие proposal не является native-evidence. Остальные открытые вопросы design.md сохраняются.

Позиции пересозданного Edit остаются открытыми. Описать внутреннее владение шрифтом в документации этапа.
- [ ] 2.3 Встроить освобождение HFONT после завершения использования всеми native-контролами/DC; не освобождать общий ресурс при частном Destroy/detach/rollback. Проверка: первичная panic/значение/стек сохраняются, cleanup panic не выбрасывается повторно, независимые операции продолжаются; живой пользователь запрещает удаление HFONT, Run сообщает сбой, нормальная остановка с cleanup failure не выдумывает первичную panic.
